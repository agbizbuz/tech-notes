# Tips & Tricks, Quick References

## ZSH
```sh
# append
path+=('/home/david/pear/bin')
# or prepend
path=('/home/david/pear/bin' $path)

# and don't forget to export to make it inherited by child processes
export PATH
```
## Quick reference
### Hidden Files
- AstroNvim - <leader>fF
- Television (files, dirs) - Ctrl + s
- Mac Finder - Cmd + Shift + .
